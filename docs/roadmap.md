# 后续路线

当前仅第一个可运行里程碑，不把规划功能算作已完成。

1. **基础运营**：机构开户，科室/医生/就诊人档案维护，医生多科室关联，医护独立权限，查询过滤与排班分页。
2. **服务变更**：停诊、替诊、批量取消、患者确认改约、操作进度与失败重试；不能只把排班设为不可用。
3. **候补与消息**：公平候补队列、限时保留、outbox、消息可靠投递、通知失败恢复。
4. **支付与超时**：明确免费预约与需支付挂号模式；占用到期、回调/释放竞争、退款补偿、对账。
5. **资源协同**：服务项目与医生/诊室/设备联合预约，统一锁顺序和冲突检测。
6. **性能验证**：固定测试数据、硬件配置与环境，分别验证热门号源和普通列表查询；记录吞吐、p95、失败率、数据库锁等待，不虚构性能指标。
7. **对接与上线**：按合作方协议接 HIS / FHIR 适配；补齐限流、监控、备份恢复、部署与隐私保护要求。
